# Umbra Blackvale

Umbra Blackvale é um RPG estratégico online competitivo focado em Comandantes, Invocações, Dungeons, ranking e economia entre jogadores.

## Visão

O objetivo de longo prazo é evoluir o projeto até um MMORPG completo.

A primeira versão será um jogo online estruturado por salas e Dungeons, preparado para crescer por módulos sem reescrever seus fundamentos arquiteturais.

## Objetivo principal do jogador

Tornar-se o Comandante número 1 do ranking.

## Pilares

- Combate assistido por turnos.
- Cartas de Invocação e Ecos de Umbra.
- Dungeons solo e em equipe.
- Economia entre jogadores sem Pay-to-Win.
- Ranking competitivo.
- Rede social integrada.
- Temporadas e mundo em expansão.

## Stack oficial

- Godot 4.5+
- C#
- ASP.NET Core (.NET 9)
- PostgreSQL
- Entity Framework Core
- Redis
- REST
- SignalR
- Docker
- GitHub Actions

## Arquitetura

- Clean Architecture.
- Servidor autoritativo.
- Cliente sem autoridade sobre dano, crítico, loot, experiência, economia, recompensas ou resultados.
- Monorepo com cliente, servidor, contratos compartilhados, testes, documentação, ferramentas e assets.
