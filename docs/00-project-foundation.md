# Fundação do Projeto

## Status

Aprovado para inicialização estrutural.

## Produto

Umbra Blackvale é tratado como produto comercial de longo prazo, não como protótipo experimental.

## Direção

A primeira entrega será um jogo online baseado em salas e Dungeons.

A arquitetura deve permitir crescimento gradual até um MMORPG completo, preservando os fundamentos de domínio, autoridade do servidor, persistência e comunicação.

## Princípios

1. O código serve ao jogo.
2. Diversão e experiência do jogador têm prioridade.
3. O servidor é autoritativo.
4. Toda decisão importante deve ser documentada.
5. Nenhuma funcionalidade entra apenas por ser interessante.
6. Não haverá Pay-to-Win.
7. Soluções temporárias e gambiarras não são aceitas como arquitetura.
8. O projeto deve considerar escalabilidade, segurança, desempenho e manutenção.

## Fonte de verdade

Em caso de dúvida ou conflito:

1. Bíblia do Projeto para visão e princípios.
2. GDD para gameplay e experiência.
3. Lore Oficial para cânone narrativo.
4. Stack Oficial para tecnologia e arquitetura.
